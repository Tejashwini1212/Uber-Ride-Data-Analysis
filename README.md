# 🚖 Uber Ride Data Analysis

An exploratory data analysis (EDA) project on Uber ride data using Python. This project analyzes ride patterns, trip purposes, travel distances, and temporal trends through data visualization and feature engineering.

---

## 📌 Project Overview

This project focuses on understanding Uber ride behavior by answering questions such as:

- What is the distribution of Business vs Personal rides?
- Which trip purposes occur most frequently?
- How are rides distributed across months and weekdays?
- What is the distribution of trip distances?
- Are there any notable patterns or outliers?

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset

The dataset contains information about Uber rides, including:

- Start Date
- End Date
- Category
- Start Location
- Stop Location
- Distance (Miles)
- Trip Purpose

---

## 📊 Exploratory Data Analysis

The notebook includes:

- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Datetime Feature Extraction
- Category Analysis
- Purpose Analysis
- Ride Distribution
- Monthly Trends
- Weekday Trends
- Distance Analysis
- Correlation Heatmap

---

## 📈 Key Insights

- Business rides account for the majority of trips.
- Most rides are relatively short in distance.
- Ride frequency varies across different months.
- Certain pickup and drop locations appear significantly more often than others.
- A small number of long-distance trips create noticeable outliers.
